# GPRO2 — Website Promosi Global Pro-eksistensi

Website statis satu halaman untuk Global Pro-eksistensi (GPro) — Pusat Kajian Strategis.

## Konsep
- Promosi dan profil lembaga, tanpa fitur interaktif pengunjung.
- Tidak ada modal, form, filter, menu hamburger, toggle tema, animasi interaktif, atau tombol WhatsApp.
- Konten: beranda, tentang GPro, bidang kajian, pendekatan kerja, karya kajian, dan informasi kontak berupa teks.
- Desain profesional, bersih, responsif, Bahasa Indonesia.
- Warna utama: merah #D00705, biru #7DB4CE, ink #493D58, latar #F8FAFD.

## Menjalankan
```bash
npm install
npm run dev
```
Kemudian buka http://localhost:3000.

```bash
npm run lint
npm run build
```

## Teknologi
Next.js 16 App Router, React 19, TypeScript, CSS murni tanpa dependensi UI.
